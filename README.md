# Pre-financials

Adaptive UK pre-advice financial fact-find.

## Privacy model
- Static client-side site.
- No analytics or external scripts.
- No form submission endpoint or database.
- Answers stay in the respondent's browser local storage unless they explicitly export a progress or handover file.
- Do not enter names, addresses, account numbers, passwords, National Insurance numbers or security credentials.

## Deployment
Static Netlify site. Publish the repository root. `robots.txt`, HTML robots meta and `X-Robots-Tag` discourage search indexing.

## Status
V4.3 pre-advice pilot. Not regulated financial, tax or legal advice and not an FCA-prescribed form.
